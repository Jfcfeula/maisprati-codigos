# Exercícios JavaScript

Este repositório contém vários exercícios em JavaScript que utilizam o pacote `readline-sync` para entrada de dados via console.

## Pré-requisitos

- [Node.js](https://nodejs.org/) instalado na sua máquina.

## Instalação

No diretório do projeto, execute o comando para instalar a dependência:

```bash
npm install readline-sync
```

## Como executar os exercícios

Para executar qualquer exercício, use o comando:

```bash
node nome_do_arquivo.js
```

Por exemplo, para executar o exercício da tabuada:

```bash
node tabuada.js
```
